      [  -SKIPPABLE-  ] ¶ FOREWARD
The formatting of this text is somewhat specific. You can skip this foreward,
but it might help to read through. When capitalized text is wrapped in square
brackets, like [GAME DIRECTORY], that is a *specified directory*. You can
always look back in the guide to see where it's defined. Any text wrapped in
right angle brackets, like ‹./snaptic.pck›, is a path. Paths will be defined in
a UNIX-y way with (/) forward slashes. Paths are always local to your game
directory, [GAME DIRECTORY], defined later in the file.

    ==-== 1. SETUP ==-==


      [  !IMPORTANT!  ] ¶ 1
Firstly, find your game directory. It can be easily found by going into Steam,
and going under (⚙  > Manage > Browse Local Files). The directory opened in your
file explorer is then defined here on as [GAME DIRECTORY].


      [  RECOMMENDED  ] ¶ 2
Next, decide the name of your mod. For the purpose of testing, you can just use
"MyTestMod". This is defined as [MOD NAME].


╭─────[ ⫎ FIGURE 1.0 ]─────────────────────────────────────────────────────╮
│ ./ [GAME DIRECTORY]                                                      │
│ ├─ GDPatch/                                                              │
│ │  ╰─ mods/                                                              │

│ │     │  ╰─ gdpatch_mod.toml                                             │
│ │     ╰─ ...                                                             │
│ │                                                                        │
│ ├─ snaptic.exe     (The packed executable, contains asset data and code) │
│ ├─ snaptic.pck     (Encrypted asset data. Unused in current build)       │
│ ╰─ theora_mosh.dll (Datamosh effect library)                             │
╰──────────────────────────────────────────────────────────────────────────╯

      [  !IMPORTANT!  ] ¶ 3
Set up your game directory to have a structure to look like [ FIGURE 1.0 ].
Make sure to replace every variable with its definition, like [MOD NAME] and
[GAME DIRECTORY]. Don't worry about GDPatch just yet, we'll get to that later.

      [  !IMPORTANT!  ] ¶ 4
Next up, let's get your [MOD] directory set up. Firstly, get your
‹gdpatch_mod.toml› set up to look like [ FIGURE 1.1 ], replacing variables,
of course. Replace [MOD ID] with your mod name converted to snake case, like
"mod_name" instead of "Mod Name". Replace [AUTHOR NAME] with an online alias,
or your real name, and [MOD DESCRIPTION] with a brief description of your mod.
[MOD VERSION] is probably just "1.0.0" for now. Best practice is to have your
version be SemVer, or Semantic Versioning. 1.0.0 is Major update 1, Minor
update 0, Micro update 0. This is similar to how this document is versioned.

╭─────[ ⫎ FIGURE 1.1 ]──────────────╮
│ id = "[MOD ID]"                   │
│                                   │
│ [meta]                            │
│ name = "[MOD NAME]"               │
│ version = "[MOD VERSION]"         │
│ authors = ["[AUTHOR NAME]"]       │
│ description = "[MOD DESCRIPTION]" │
